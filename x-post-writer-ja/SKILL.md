# 目的

人がスクロールを止めて、続きを読み、感情が動き、リプライ・引用・保存・シェアしたくなるX投稿を書く。

いいねの数より、会話が生まれること、保存されること、人に送られることを優先する。

このスキルは「何をどの順で書くか」を決める。仕上げ（AIっぽさを消す・語り口を整える）は x-humanizer-ja が担当する。

# 絶対ルール：事実と体験を作らない

- 数字・固有名詞・日付・出典は、素材にあるものだけを使う。
- 書き手の体験・失敗・感想は、素材か本人の話にあるものだけを書く。
- 体験があると強くなるのに材料がない場合は、本文に入れない。投稿の後に「ここに体験が入ると強くなる（例：○○を試したか）」と一行メモを残す。
- このファイルの例文に出てくる数字や体験は型の見本。実際の投稿に流用しない。

# 書く前に決める3つ

1. この投稿で狙う反応はどれか。リプライ／引用リポスト／ブックマーク／リンクのシェアから1つ選ぶ。
2. 読者がどんな場面で、心の中で何と言っているか。属性（「副業したい人」）ではなく場面（「夜、通知ゼロの画面を見ている人」）で決める。
3. 1行目の型をどれにするか（下の「1行目の型」から選ぶ）。

## Xで評価されやすい行動

上ほど強い。投稿を設計するときは、上の行動が起きる形を優先する。

1. リプライ。特に、書き手がリプライに返して会話が続くこと。
2. リンクをコピーして人に送られること。
3. 引用リポスト。引用した人が自分の意見を足せる主張。
4. ブックマーク。後で見返したい手順・一覧・比較。日本語圏では人に見られずに保存できるので、特に起きやすい。
5. 投稿直後の反応。最初の反応が早いほど広がる。

# 読ませる5段階

## 1. スクロールを止める（0〜0.5秒）

- パターン中断：常識を少し裏切る。対照を並べる。極短文で切って改行する。
- 自己関連性：属性ではなく、具体的な場面や心の中の言葉で「自分のことだ」と思わせる。

## 2. 続きを読ませる（0.5〜3秒）

- 好奇心ギャップ：読者がすでに知っている前提の上に、小さな未知を一つ残す。全部知らない話は読まれない。
- 損失回避：「得する」より「このままだと損している」の形を優先する。

## 3. 信頼と没入を作る（本文）

- 具体性：数字・固有名詞・時間・場所・体の動きを入れる。抽象語で済ませない。
- 必要なら短い物語にする。緊張（困っていた・失敗した）から転換（こうしたら変わった）へ。

## 4. 感情を動かす

- 高い覚醒の感情で終える。知的な興奮、驚き、まっとうな怒り、前向きな焦り。
- 悲しみや「なるほど」だけで終わらせない。
- フックで作った期待を、本文で少し上回る。

## 5. 出口を作る

- リプライ狙い：9割正しい大胆な言い切りに、1割の余白を残す。言い切りに「違う」と言いたくなる隙間があると、人は書き込む（カニンガムの法則）。
- 引用狙い：シェアした人が「自分はこう考える人間だ」と示せる内容にする。
- ブックマーク狙い：後で見返せる手順・一覧・比較にする。

# 1行目の型

1行目はできるだけ短くする。タイムラインでは最初の1〜2行しか読まれない。

例文の数字は見本。素材にある数字に置き換える。

1. 常識の逆を言う
   「毎日投稿をやめたら、反応が増えました。」
2. 具体的な数字・結果
   「固定ポストを1つ変えただけで、プロフィールの閲覧が倍になった。」
3. 失敗 → 変化
   「去年はこれで完全に失敗していました。」
4. 未完の文で止める
   「みんなやってるのに、実は逆効果だったこと：」
5. 読者を名指しする
   「投稿のネタが3日で尽きる人、ちょっと聞いてほしい。」
6. 問題提起と約束
   「投稿しても反応ゼロの人がやりがちなこと。これをやめるだけで変わります。」
7. 答えやすい二択
   「毎日の短文と、週2回の長文。どっち派ですか。」
8. 定説に穴を開ける
   「『継続が大事』はその通り。でも伸びている人は、続け方が違う。」
9. 大きな変化を言い切る
   「いよいよ〜の時代が来ました。」本文で必ず事実と数字で裏づける。
10. 本音の前置き
   「正直、これ言ったら叩かれそうだけど。」中身が本当に少数派の意見のときだけ使う。

直近の投稿と同じ型が続いたら、別の型を選ぶ。

# 語り口の引き出し

日本語のXで反応が取りやすい語り口。内容に合うときだけ使う。

1投稿に1〜2個まで。語り口だけ強くて中身が普通だと、かえって信用を落とす。

## 本音・正直系

- 「正直、これ言ったら叩かれそうだけど」
- 「多分言ったらすごい叩かれるんだろうけど、正直な感想として」
- 「本当は教えたくないけど」

使う条件：中身が本当に少数派の意見か、手間をかけて見つけた情報であること。

## 共感・ミラーリング系

- 「これめっちゃわかる」
- 「〜って思うの、私だけ？」
- 「わかる人おる？」

使う条件：読者の多くが口に出さずに思っていることを、そのまま言葉にできるとき。

## 余白を残す言い切り

- 「結局〇〇に集約される説」
- 「これ以外にもう無いですよね？」
- 「〜だと思うんだけど、違う意見の人いる？」

使う条件：リプライを狙うとき。「あなたはどう思う？」より、自分の答えを先に言ってから聞く方が書き込まれやすい。

## 言語化系

- 読者がモヤモヤしていることを一文でスッキリさせる。
- 「あ、そこを見てるの？」と思わせる着眼点を一つ入れる。
- 入りの例：「〜がしんどい理由、たぶんこれです。」「〜な人って、能力じゃなくて〇〇を見てる。」

## カジュアル・関西寄り

- 「〜やろ」「〜やで」「そんなん」「せやけど」
- アカウントの普段の口調が近いときだけ使う。急に一投稿だけ関西弁にしない。

# 本文の組み立て

1投稿に1メッセージ。詰め込まない。

改行を多めにして、3行以上の塊を作らない。

フックで約束したことは本文で必ず回収する。

## 型A：会話を生む（リプライ狙い）

```
[言い切り（1行）]

[そう思う理由・場面を2〜3行]

[自分の答えを添えた問いかけ]
```

## 型B：価値観を代弁する（引用リポスト狙い）

```
[多くの人がモヤモヤしていることの言語化（1〜2行）]

[具体的な場面を1つ]

[読者が「そうそう」と言える一文で締める]
```

## 型C：保存させる（ブックマーク狙い）

```
[何が手に入るかが分かる1行目]

[手順・一覧・比較を3〜5個]

[いちばん効いた1つに一言だけ補足]
```

## 型D：短い物語（没入狙い）

```
[緊張：困っていた場面・失敗（1〜2行）]

[転換：何を変えたか]

[結果：数字か具体的な変化]

[判断：自分はこれからどうするか]
```

# スレッドにする場合

- 1投稿目だけで十分に引きつける。1投稿目で何が読めるかを約束する。
- 2投稿目以降は1投稿1要点。
- 最後の投稿で1投稿目の約束を回収する。

# 締め方

教訓・まとめで締めない。次のどれかで終える。

- 自分の判断（「僕はこっちにします」）
- 自分の答えを添えた問いかけ
- 印象に残る一言
- 軽い誘導（「固定ポストに手順を置いています」など）

本文を書きすぎない。補足は投稿直後に自分でリプライとして足す前提にして、余白を残す。

# 画像

画像・スクリーンショット・図解があると反応が上がる前提で書く。

付けられる場合は、本文の最後に「画像案：○○」と一行添える。本文で画像の説明を繰り返さない。

# 避けること

- フックだけ強くて中身が薄い
- 煽りや道徳的な怒りの使いすぎ
- 抽象的な綺麗事だけの投稿
- 読者を絞りすぎて誰にも刺さらない
- 整いすぎて、AIが書いたように見える文章
- 「今日は〇〇についてお話しします」などの前置き
- 根拠のない数字・過度な誇張

# 書いた後

書き上げたら x-humanizer-ja の手順で仕上げる。

x-humanizer-ja が入っていない場合は、下のチェックリストだけ通す。

# 最終チェックリスト

- [ ] 1行目で「自分のことだ」と感じるか
- [ ] 小さな好奇心ギャップがあるか
- [ ] 具体的な数字・場面が入っているか
- [ ] フックの約束を本文で回収しているか
- [ ] 読み終わったときに感情が残るか
- [ ] リプライしたくなる余白、または保存したくなる具体性があるか
- [ ] 狙った反応（リプライ／引用／保存／シェア）に合った締めになっているか
- [ ] 素材にない事実・数字・体験が入っていないか
- [ ] AIが書いた感じがしないか

# 例（架空の題材）

素材：個人でハンドメイドのアクセサリーを売っている。きれいに揃えた方が売れると思って、商品写真をずっと白背景で撮っていた。身につけた写真に変えた翌月、作品ページのブックマーク数が増えた（数字は素材にない）。次は服の色を変えた写真を3パターン試すつもり。

```
白背景の商品写真、やめました。

きれいに揃えた方が売れると思って、ずっと白背景で撮っていたんです。

身につけた写真に変えた翌月、作品ページのブックマークが目に見えて増えました。

買う人が見たいのは、商品そのものより「自分がつけたらどうなるか」だったのかもしれません。

次は、服の色を変えた写真を3パターン並べてみます。

商品写真、白背景派ですか。着用派ですか。

画像案：同じピアスの白背景写真と着用写真の比較
```

狙い：リプライ。数字は素材にないので「目に見えて増えた」に留めた。
