# x-skills-ja

日本語のX（旧Twitter）投稿のための、Claude用スキル2本です。

| スキル | 役割 |
|---|---|
| `x-post-writer-ja` | 素材やテーマから、X投稿を書き起こす |
| `x-humanizer-ja` | 書いた投稿から「AIが書いた感」を消して、自然な語り口に仕上げる |

書くスキルと、仕上げるスキルを分けています。

片方だけでも使えます。

## それぞれのスキルの中身

### x-post-writer-ja（書く）

リプライ・引用・ブックマークが生まれる投稿を組み立てます。

- 書く前に「狙う反応」「読者の場面」「1行目の型」を決める
- スクロールを止める → 続きを読ませる → 没入 → 感情 → 出口、の5段階
- 1行目の型10個
- 日本語のXでよく使われる語り口（本音系・共感系・余白を残す言い切り・言語化系・関西寄り）
- 狙う反応ごとの本文の型（会話・引用・保存・物語）
- 最終チェックリスト

### x-humanizer-ja（仕上げる）

下書きのAIっぽさを消し、人が話しているように読める文面にします。

- AIっぽいパターン25個と、その直し方
- 語り口を自然に入れるルール（1投稿1〜2個まで、中身が伴うときだけ）
- 口調（ですます・だ・タメ口・関西寄り）を最初に決めて最後まで通す
- 自分の投稿を貼る「見本」欄
- 書き換えの手順と最終チェックリスト
- Before / After例（架空の題材）

どちらのスキルにも「事実と体験を作らない」を絶対ルールとして入れています。

数字や体験は、渡した素材にあるものしか使いません。

## いちばん簡単な使い方

GitHubのURLをコピーして、Claudeに送るだけでも使えます。

```
https://github.com/ecsamurai/x-skills-ja
このURLにあるx-post-writer-jaとx-humanizer-jaを使って、X投稿を書いて。
```

決まった時間に投稿させたいときは、Claude Codeに「これをスケジュールに組み込んで」と頼みます。

投稿のやり方は、ブラウザ操作でも、Claudeのデスクトップアプリからでもかまいません。

## 入れ方

### Claude（claude.ai・デスクトップアプリ）

1. このリポジトリをダウンロードする。
2. `x-post-writer-ja` と `x-humanizer-ja` のフォルダを、それぞれzipにする。
3. Claudeの設定のスキル画面から、zipをアップロードする。

### Claude Code

スキルのフォルダを `~/.claude/skills/` に置きます。

```bash
git clone https://github.com/ecsamurai/x-skills-ja.git
cp -r x-skills-ja/x-post-writer-ja ~/.claude/skills/
cp -r x-skills-ja/x-humanizer-ja ~/.claude/skills/
```

プロジェクトの中だけで使う場合は、`.claude/skills/` に置きます。

## 使い方の例

### 素材から投稿を書く

```
次の素材でX投稿を書いて。狙いはリプライ。

・商品写真を白背景から着用写真に変えた
・翌月、作品ページのブックマークが増えた
```

### 下書きを仕上げる

```
このX投稿、AIっぽさを消して。口調はタメ口で。

（下書きを貼る）
```

### 書いて仕上げるまで一度に

```
この素材でX投稿を書いて、x-humanizer-jaで仕上げて。
```

## カスタマイズ

### 自分の文体に育てる

いちばん効くのは、`x-humanizer-ja/SKILL.md` の「見本」欄に、自分の投稿を貼ることです。

反応がよかった投稿を、原文のまま2〜3本貼ってください。

貼ったら、見本ごとに「取る特徴」を3〜5行書きます。

例：事実を一つ置いたらすぐ試した話に入る／評価をはっきり言う／教訓で締めない。

見本があると、口調・語尾・改行のリズムは見本が優先されます。

使いながら「この直しは違う」と思ったら、その例を「AIっぽいパターン」に足していくと、どんどん自分の文体に寄っていきます。

### 口調を固定する

アカウントの口調が決まっているなら、「最初に口調を決める」の節に一行足します。

例：「このアカウントはですます調。関西寄りの語り口は使わない。」

### 使わない言葉を足す

業界やアカウントで避けたい言葉があれば、「AIっぽいパターン」の「硬い言い回し」に並べて足します。

### 語り口を足す

自分のタイムラインで反応が取れている言い回しを見つけたら、「語り口を自然に入れる」の表に一行足します。

使う場面も一緒に書いておくと、合わない投稿に入りにくくなります。
