# 目的

X投稿の下書きを、人間がその場で書いたように読める文面に仕上げる。

あわせて、日本語のXで実際に使われている語り口を、内容に合うところだけ自然に入れる。

いちばん大事にするのは二つ。

一つは、AIっぽい決まり文句と整いすぎた形を消すこと。

もう一つは、書き手の温度（勢いのある入り、本音の一言、少しの崩れ）を消さずに残すこと。

# 絶対ルール：事実と体験を作らない

このスキルは書き換えるだけのもの。ネタを足すものではない。

- 事実・数字・固有名詞・日付・出典は変えない。足さない。
- 書き手の体験・失敗・感想は、元の文か本人の話にあるものだけを書く。
- 「正直、叩かれそうだけど」のような語り口を入れるために、意見や体験を作らない。中身が伴わない語り口は入れない。
- 体験を足したいのに材料がない場合は、本文に入れない。書き換えた文の後に「ここに体験があると強くなる（例：○○を試したか）」と一行メモを残す。
- 元の文にある本音・皮肉・感想は、丁寧に丸めて消さない。
- このファイルの例文の体験や数字は見本。実際の投稿に流用しない。

# 最初に口調を決める

書き換える前に、そのアカウントの普段の口調を一つ決める。

- ですます調（丁寧だが堅くない）
- だ・である調（言い切り中心）
- タメ口（会話調）
- 関西寄り（「〜やで」「〜やろ」）

決めた口調を投稿の最後まで通す。語り口を足すときも、その口調に合わせて形を変える。

例：ですます調なら「わかる人おる？」より「わかる人、いますか」。タメ口なら「わかる人おる？」のまま。

`## 見本` に本人の投稿がある場合は、見本の口調を優先する。

# AIっぽいパターンと直し方

見つけたら直す。例文の体験は架空の見本。

## 決まり文句

1. 前置きで始める
   NG：結論から言うと、〜です。／今日は〇〇について解説します。
   直し：前置きを消して、結論そのものを1行目に置く。

2. 「重要」「大切」で締める
   NG：〜することが大切です。／重要なのは〇〇です。
   直し：何をしたら何が起きたかを書く。「大切」と言わずに、大切だと分かる事実を置く。

3. 硬い言い回し
   NG：〜することができます／〜を活用する／しかしながら／〜と言えるでしょう／〜ではないでしょうか／〜を考慮すると
   直し：〜できます／〜を使う／でも／〜です／〜だと思います

4. まとめの決まり文句
   NG：いかがでしたか／まとめると／今後の展開が注目されます
   直し：消す。最後の一文を、自分の判断か問いかけにする。

5. 呼びかけの決まり文句
   NG：ぜひ試してみてください！／〇〇な方は必見です！
   直し：「僕は次にこれをやります」「気になる人は固定ポストに置いてます」のように、自分の行動か具体的な場所で終える。

6. 「あなたはどう思いますか？」で締める
   NG：あなたはどう思いますか？
   直し：自分の答えを先に置いてから聞く。「僕は〇〇派です。違う意見の人いますか。」

## 形が整いすぎている

7. 文末が全部同じ
   NG：〜です。〜です。〜です。〜です。
   直し：同じ語尾は2回続けたら変える。言い切り、問いかけ、話し言葉の語尾を混ぜる。

8. 無理に3つにまとめる
   NG：ポイントは3つあります。
   直し：本当に大事な1つから書く。2つなら2つでいい。

9. 教訓で締める
   NG：だからこそ、小さく始めることが大事なんですよね。
   直し：教訓の文を消し、その前の具体的な一文で終える。

10. 起承転結がきれいすぎる
    NG：課題 → 解決策 → メリット → 今後の展望、の順に整然と並ぶ。
    直し：いちばん強い事実か結果を1行目に上げる。展望の文は消す。

11. 両論を並べて「一長一短」で終える
    NG：メリットは〜、デメリットは〜。一長一短ですね。
    直し：どちらを取るか、自分の判断を一文で書く。

12. 見出しやラベルで区切る
    NG：**ポイント：**〜／【結論】〜／✅〜
    直し：太字・墨付き括弧の見出し・チェック絵文字を外し、普通の文と改行で区切る。

## 記号と飾り

13. 全角ダッシュで間を作る
    NG：結果は——予想外でした。
    直し：結果は予想外でした。

14. 感嘆符と絵文字を重ねる
    NG：本当に驚きました！！🔥✨
    直し：何が起きたかをそのまま書く。感嘆符は1投稿に1つまで。絵文字は普段使わないアカウントなら0。

15. ハッシュタグを並べる
    直し：本文中のハッシュタグは消す。どうしても要るなら末尾に1つだけ。

## 中身が薄い

16. 抽象語で済ませる
    NG：効率が大幅に上がりました。
    直し：何が、何分から何分になったかを書く。素材に数字がなければ、具体的な場面を書く（「夜にやっていた作業が、朝のうちに終わるようになった」）。

17. 書き手が出てこない
    NG：画像生成AIはまだ完璧ではありません。
    直し：元の文に体験があれば前に出す。「試したら、日本語の指示ではまだ全然ダメでした。」体験がなければ足さない。

18. 伝聞の語尾が続く
    NG：〜のようです。〜だそうです。〜と見られています。
    直し：伝聞は出典の事実を伝える所だけ、1投稿に2回まで。自分の見立ては「〜です」「〜だと思います」と言い切る。

19. 「〜ですよね」で同意を取りに行く
    NG：投稿を続けるのって大変ですよね。
    直し：投稿を続けるのは、3日目あたりでネタが尽きます。（具体的な場面に変える）

20. 「かも」「もしかしたら」の連発
    直し：本当に分からない部分だけに使う。確かなことは言い切る。

## 文の形

21. 読点で長くつなぐ
    NG：AIで下書きを作るようになったことで、投稿の数が増えて、反応も少しずつ良くなってきています。
    直し：AIで下書きを作るようになりました。

    投稿の数が増えて、反応も少しずつ良くなっています。

22. 短文と体言止めの連発
    NG：試した。ダメだった。使えない。結論、不要。
    直し：試しましたが、日本語ではまだダメでした。

23. 改行のない塊
    直し：3行以上の塊を作らない。基本は一文ごとに改行して一行空ける。ひと続きの話は、空行なしで2行続けてよい。

## 温度を消しすぎる

24. 本音や勢いを丸める
    NG：「正直これはひどい」を「改善の余地があると考えられます」に言い換える。
    直し：元の文の本音は残す。人そのものへの攻撃に読める部分だけ、事実への感想に寄せる。

25. 全部を丁寧に閉じる
    NG：最後の一文まで、すべての疑問に答えて閉じる。
    直し：一つだけ余白を残す。補足は投稿直後のリプライに回す前提で、本文を書きすぎない。

# 語り口を自然に入れる

日本語のXで反応が取りやすい語り口を、内容に合うところだけ入れる。

ルールは四つ。

- 1投稿に1〜2個まで。
- 中身が伴うときだけ使う。「叩かれそう」と言うなら、本当に少数派の意見であること。
- 決めた口調に合わせて形を変える。
- 直近の投稿と同じ語り口を続けない。

## 本音・正直系

| 語り口 | 使う場面 |
|---|---|
| 「正直、これ言ったら叩かれそうだけど」 | 多数派と逆の意見を言うとき |
| 「多分言ったらすごい叩かれるんだろうけど、正直な感想として」 | 自分が使った・見たうえでの率直な評価 |
| 「本当は教えたくないけど」 | 手間をかけて見つけた情報を出すとき |

入れ方：1行目に置き、2行目ですぐ中身を言う。前置きを2行以上続けない。

## 共感・ミラーリング系

| 語り口 | 使う場面 |
|---|---|
| 「これめっちゃわかる」 | 他の人の投稿への引用・リプライ |
| 「〜って思うの、私だけ？」 | 口に出しにくい本音を投げるとき |
| 「わかる人おる？」 | タメ口・関西寄りのアカウントで共感を集めるとき |

入れ方：「〜」の部分は、読者が心の中で呟いている言葉そのものにする。説明的な言葉にしない。

NG：「SNS運用の継続に困難を感じるの、私だけ？」
直し：「投稿ボタン押す直前に全部消したくなるの、私だけ？」

## 余白を残す言い切り

| 語り口 | 使う場面 |
|---|---|
| 「結局〇〇に集約される説」 | 自分なりの結論を言うが、反論も歓迎したいとき |
| 「これ以外にもう無いですよね？」 | 一覧や方法を出して、足りない分をリプライで集めたいとき |
| 「〜だと思うんだけど、違う意見の人いる？」 | 締めでリプライを集めたいとき |

入れ方：9割は言い切る。最後の1割だけ問いかけにする。最初から迷っている書き方にしない。

## 言語化系

- 読者のモヤモヤを、一文で言い当てる。「〜がしんどいの、たぶん〇〇のせいです。」
- 「あ、そこを見てるの？」と思わせる着眼点を一つ入れる。誰もが言っている理由ではなく、少しずれた角度から言う。

## カジュアル・関西寄り

- 「〜やろ」「〜やで」「そんなん」「せやけど」
- アカウントの口調が近いときだけ使う。ですます調の投稿に一語だけ混ぜない。

# 人間らしさを足すコツ

- 読者が心の中で呟いている言葉を、そのまま書く。
- 体の動きや時間を書く。「夜中2時に通知を見て」「3回書き直して」など（元の文にある場面だけ）。
- 自慢やマウントにならない範囲で、元の文にある失敗や迷いを前に出す。
- 完璧に閉じない。少しの余白か本音を残す。
- 話し言葉の入り（「とにかく」「いよいよ」「正直」）は勢いとして残す。1投稿に1〜2回まで。

# 文の形のルール

1. 読点で説明をつなげず、話の区切りで文を分ける。一文一内容。
2. 消しても自然に読める読点は取る。誤読を防ぐ読点は残す。
3. 自然につながる説明は一文のまま。短文や体言止めを連発しない。
4. 基本は一文ごとに改行して一行空ける。
5. 1行目はできるだけ短くする。
6. 文字数は元の文から大きく増やさない。1投稿なら140〜350字を目安にする。
7. 他の会社やツールを断定的に悪く言わない。自分が使ったうえでの率直な感想は残してよい。

# 見本（ここに自分の投稿を貼る）

自分が書いて反応がよかった投稿を、原文のまま2〜3本ここに貼る。

貼ったら、見本ごとに「取る特徴」を3〜5行書く。例：事実を一つ置いたらすぐ試した話に入る／評価をはっきり言う／教訓で締めない。

# 書き換えの手順

1. 元の文から、事実・数字・固有名詞・日付・出典・体験・本音や感想を抜き出す。
2. 口調を決める（見本があれば見本に合わせる）。
3. 「AIっぽいパターン」を上から順に探して直す。
4. いちばん強い事実・結果・本音を1行目に上げる。1行目はできるだけ短くする。
5. 内容に合う語り口があれば、1〜2個だけ入れる。合うものがなければ入れない。
6. 文の形のルールで整える。
7. 締めを、自分の判断・自分の答えを添えた問いかけ・印象に残る一言のどれかにする。
8. 元の文と照らし合わせて、事実が全部残っていて、新しい事実・体験・意見が増えていないかを確かめる。
9. 語尾の重なり、「ですね」「かも」、伝聞の語尾、感嘆符の回数を数える。

- [ ] 文末が同じ形で3回以上続いていない
- [ ] 教訓やまとめで締めていない
- [ ] 太字・見出し・全角ダッシュ・絵文字の重ね使いがない
- [ ] 読点で長くつないでいない。ぶつ切りにもなっていない
- [ ] 抽象語を具体的な場面か数字に置き換えた
- [ ] 語り口は1〜2個までで、中身が伴っている
- [ ] 口調が最後まで揃っている
- [ ] 元の文の本音・勢い・感想を消していない
- [ ] 余白が一つ残っている
- [ ] 事実・数字・固有名詞・日付が元の文と同じで、増えていない

# Before / After 例（架空の題材）

## 例1：決まり文句と整いすぎを消す

元の文にある情報：X投稿の下書きをAIで作り始めた。最初の1週間は反応が落ちた。原因は、どの投稿も「〜が大切です」で終わっていたこと。締めを自分の判断に変えたら、リプライが来るようになった。今は締めだけ自分で書いている。

Before：
結論から言うと、AIで投稿を作る際に重要なのは「締め方」です。私はAIで下書きを作り始めましたが、最初の1週間は反応が低下しました。原因を分析したところ、すべての投稿が「〜が大切です」で終わっていたことが判明しました。締めを自分の判断に変更したことで、リプライが増加しました。現在は締めのみ自分で執筆しています。ぜひ皆さんも試してみてください！

After：
AIに書かせた投稿、最初の1週間は反応が落ちました。

見返したら、全部「〜が大切です」で終わっていたんです。

締めを自分の判断に変えただけで、リプライが来るようになりました。

AIの下書き、締めだけは自分で書くことにしています。

（直したところ：前置きと「重要」を消した。結果を1行目に上げた。呼びかけの締めを消し、元の文にある今のやり方で終えた。新しい体験は足していない）

## 例2：語り口を入れる

元の文にある情報：毎日投稿は必須ではないと考えている。週3回に減らしてから、1本ずつに時間をかけられるようになった。少数派の意見だと自覚している。口調はタメ口。

Before：
毎日投稿は必ずしも必要ではないと考えています。週3回に減らしたことで、1本あたりにかけられる時間が増えました。投稿頻度より質が大切だと言えるでしょう。

After：
正直、これ言ったら叩かれそうだけど。

毎日投稿、別にしなくていいと思ってる。

週3回に減らしてから、1本ずつちゃんと考える時間ができた。

毎日出すのがしんどくなってる人、一回減らしてみてもいいと思うんだけど、違う意見の人いる？

（直したところ：少数派の意見だと元の文にあるので、本音系の語り口を1行目に入れた。「質が大切だと言えるでしょう」を消し、余白を残す言い切りで締めた。語り口は2個）
